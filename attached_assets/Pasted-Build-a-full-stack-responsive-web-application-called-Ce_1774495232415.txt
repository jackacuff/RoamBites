Build a full stack responsive web application called Central Oklahoma Food Truck Tracker.

The goal of this app is to help three user groups:
1. Customers who want to find food trucks that are open now or opening soon
2. Vendors who want to manage their truck profile, menu, and schedule
3. Event organizers who want to create events and invite or assign food trucks

This is an MVP, but I want it to feel polished, real, and testable. The app should be designed specifically for Central Oklahoma to start, with sample data focused on Oklahoma City, Edmond, Norman, Moore, Yukon, and surrounding areas.

Build this as a responsive web app that works very well on both desktop and mobile browsers. It should feel close to a mobile app when viewed on a phone. Prioritize clean UI, easy navigation, and fast load times.

TECH STACK
Use a stack that works well in Replit and is easy to run and test.
Preferred stack:
- Frontend: React with Vite
- Backend: Node.js with Express
- Database: SQLite for MVP simplicity
- ORM: Prisma if practical, otherwise use a simple structured SQLite setup
- Styling: Tailwind CSS or a very clean modern CSS system
- Maps: Use Leaflet with OpenStreetMap if possible so we do not need paid Google Maps keys for the MVP
- Authentication: simple email/password auth with session based or token based auth
- State management: keep it simple
- Deployment: configure it so it can run inside Replit easily

If any of the above needs to be adjusted to make it work better inside Replit, choose the best equivalent but keep it simple and production minded.
