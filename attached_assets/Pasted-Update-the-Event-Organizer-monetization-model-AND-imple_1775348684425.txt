Update the Event Organizer monetization model AND implement a fully built-out Featured Event system. This is an ADDITION and REFINEMENT to the existing event and pricing system.

GOAL
Create a low-friction organizer experience (free to start), monetize through usage, and introduce a high-value Featured Event upgrade that clearly improves visibility and drives conversions.

--------------------------------------------------
1. EVENT ORGANIZER PRICING MODEL (USAGE-BASED)
--------------------------------------------------

A. Free Event Creation
- Organizers can create events for free
- No upfront cost

B. Per Event Fee
- Charge when:
  - event is published OR
  - event is opened to vendors (pick one consistent trigger)

- Default:
  $10–$30 per event (admin configurable)

- Show this fee clearly before publishing

C. Transaction Fee
- Platform takes % of vendor spot payments
- Default:
  10–15% (admin configurable)

--------------------------------------------------
2. FEATURED EVENT SYSTEM (CORE UPGRADE)
--------------------------------------------------

Add a paid upgrade:
- “Featured Event”

Suggested price:
- $20–$50 per event (admin configurable)

This must NOT be just a badge.
It must provide REAL visibility improvements across the app.

--------------------------------------------------
3. DATABASE / BACKEND
--------------------------------------------------

Add fields to Event model:
- isFeatured (boolean)
- featuredPurchasedAt (datetime)
- featuredExpiresAt (optional)
- featuredPriorityScore (optional)

Must be editable by admin and set during purchase flow.

--------------------------------------------------
4. EVENT CARD VISUAL DIFFERENTIATION
--------------------------------------------------

Featured events must look different:

- “Featured” badge
- stronger border or accent color
- slightly higher visual weight
- better use of cover image
- optional star/spotlight icon

Do NOT make this subtle.

--------------------------------------------------
5. EVENT LISTING PRIORITY
--------------------------------------------------

Across all event lists:

Sort logic:
1. Featured events first
2. Then by soonest date

Apply to:
- main events page
- event search results
- discovery sections
- vendor marketplace views
