Improve the event detail page to make it more interactive, more useful, and easier to explore. Do NOT redesign the entire app. This is a refinement of the current event page.

GOAL
Make the event page feel more premium and interactive, especially around the map and truck lineup. The page should help users quickly understand the event, explore truck locations, and take action.

PRIORITY 1: EXPANDABLE MAP

1. Add expandable map behavior to the “Location & Trucks” section.
- Users should be able to tap the map or tap an “Expand Map” button
- This should open the map in a larger view, ideally a full-screen modal or large overlay
- The expanded map should be much easier to read and allow users to clearly see:
  - truck pins
  - event location
  - spacing between trucks

2. Expanded map functionality must include:
- zoom in / zoom out
- pan freely
- close button (X)
- smooth open/close animation
- clear truck pin visibility

3. Truck interaction on the expanded map
- When a user taps a truck pin, show:
  - truck name
  - cuisine
  - “View Truck” action

4. Connect truck lineup and map interaction
- When a user clicks a truck in the Food Truck Lineup, automatically highlight that truck on the map
- Ideally also zoom or center the map on that truck
- Remove reliance on users reading instructional text
- Make the interaction feel obvious through behavior

PRIORITY 2: EVENT PAGE ACTIONS

5. Add action buttons near the top of the event page
Add a clear action row near the event title/header with:
- Directions
- Save Event
- Add to Calendar

These should be easy to access and visually clean.

The current header is too flat and static.

  - Upcoming

Do NOT make it flashy or overdesigned.

PRIORITY 4: IMPROVE FOOD TRUCK LINEUP
