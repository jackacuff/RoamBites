- Prioritize actions that help each role accomplish their main objective quickly.
- Add a small “Today” or “Now” summary block near the top of the menu when relevant.
- Make the app feel more dynamic with badges, counts, and status indicators where possible.
- Preserve a clean modern mobile-first design consistent with the current RoamBites look and feel.
- Keep the UI lightweight and uncluttered.
- Make sure each role feels like a different app experience, not just the same menu with one or two renamed items.
- Keep role switching and impersonation support intact.
- Make the menu component modular and role-driven so future role changes are easy to manage from a single config object.

Global menu improvement requirements:

- Add support for badges like “2 new”, “3 pending”, “6 open”, etc.
- Add support for a featured primary action near the top for roles where that makes sense.
