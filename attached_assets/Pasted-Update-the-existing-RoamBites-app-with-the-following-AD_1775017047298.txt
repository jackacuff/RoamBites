  - Instagram
  - Facebook
  - TikTok
  - X

  - Post Today’s Schedule
  - Post Special/Discount
  - Post Event Appearance

  - caption

  - copy caption
  - download image

- The goal is to make RoamBites the hub for social posting and drive customers back into the app.

- Do not allow customers to bypass organizer pricing indefinitely.
- Allow limited customer event usage for small personal needs.
- Suggested configurable limits:
  - 1 event per 6 or 12 months
  - and/or max 1 to 2 trucks per event
- These limits should be configurable in admin settings.
- Track:
  - number of events created by the user
  - trucks added per event
  - rolling time window
- If the user exceeds limits, prompt them to upgrade/activate Event Organizer role.
- Example prompt:
  “Looks like you’re hosting multiple or larger events. Upgrade to an Event Organizer account to unlock full event management features.”
- Keep this fair, low-friction, and monetization-protective.
