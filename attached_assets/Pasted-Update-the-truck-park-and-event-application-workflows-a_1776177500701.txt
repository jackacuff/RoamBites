Update the truck park and event application workflows across RoamBites to make sure open spots can actually be applied for, closed spots can support waitlists, and the backend/admin workflows make sense for all user types involved.

GOAL
Make truck parks and events function like real two-sided marketplaces with a complete workflow for:
- food truck vendors
- event organizers
- truck park owners/operators
- admins

This is not just a frontend fix. Do a full workflow and backend logic review so the system makes sense end-to-end.

--------------------------------------------------
1. TRUCK PARK OPEN SPOTS MUST BE ACTIONABLE
--------------------------------------------------

Current issue:
- truck parks may show that spots are open
- but vendors are not clearly able to apply for those spots

Required fix:
- if a truck park has open spots, show a clear CTA for vendors such as:
  - “Apply for Spot”
  - “Reserve Spot”
  - “Request Spot”

This CTA must:
- be visible on the truck park detail page
- only appear when appropriate
- lead into a real application/request flow

The vendor should not just see that a spot is available. They must be able to take action immediately.

--------------------------------------------------
2. WAITLIST FOR FULL TRUCK PARKS
--------------------------------------------------

If there are no open spots, vendors should still be able to express interest.

Required behavior:
- show a CTA such as:
  - “Join Waitlist”
  - “Request Waitlist Spot”

This should:
- create a waitlist request record
- tie the request to the vendor/truck
- notify or surface this request to the truck park owner/operator
- allow the owner/operator to manage waitlist entries

Waitlist requests should include:
- truck/vendor identity
- contact info
- optional notes/message
- timestamp
- status (waiting, contacted, approved, declined, etc. if practical)

--------------------------------------------------
3. EVENT APPLICATION / WAITLIST WORKFLOW SHOULD MATCH THIS MODEL
--------------------------------------------------

Apply similar logic to events.

If an event has open vendor spots:
- vendor should be able to apply/reserve/request a spot clearly

If event spots are full:
- vendor should be able to join a waitlist or request consideration

Unify the marketplace behavior so vendors have a familiar experience across:
- truck parks
- events

The UX should feel consistent.
